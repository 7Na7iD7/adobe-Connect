<h1 align="center">
  🎥 Adobe Connect Meeting Downloader & Converter
</h1>

<p align="center">
  <strong>Complete toolkit to download and convert Adobe Connect recorded meetings into MP4 videos</strong>
</p>

<br>

## 📁 Repository Structure

| Folder | Description |
|--------|-------------|
| `convert/` | Conversion scripts (`convert.bat`) and temporary files |
| `pic/` | Step‑by‑step visual guides (screenshots) |
| `tool/` | Portable tools (`ffmpeg.exe` – no install needed) |
| `راهنما/` | Complete Persian documentation |

<br>

## 🚀 Quick Start

1. **Read the guide** – Start with documents inside `راهنما/` folder
2. **Follow the images** – Use screenshots in `pic/` for visual steps
3. **Run the converter** – Place meeting ZIP file in `convert/` and execute `convert.bat`

<br>

## 🖥️ Requirements

- Windows 10 or 11
- No FFmpeg installation needed – portable version in `tool/`
